# Stroke Data Ecosystem Maturity Assessment
This repository contains the R scripts used to analyse data for: "Readiness of Stroke Data Ecosystems for Evidence-Based Care in Uganda: A Multicenter Data Capability Maturity Assessment"

## Contents
- Data cleaning and preparation
- Calculation of maturity scores
- Generation of tables and figures

## Software
Analysis was conducted using R.

## Data availability
The underlying study data are not publicly available. The analysis code is provided to support reproducibility.
